Luar biasa! Semangat yang sangat bagus. Sekarang kita masuk ke kepingan puzzle utama yang terakhir untuk sang Admin: Modul Data Siswa.

Sebelum kita membuat halamannya, ada satu hal teknis yang perlu kita selesaikan. Pada desain database awal kita, tabel users belum memiliki kolom untuk menyimpan data Kelas bagi seorang siswa.

Oleh karena itu, kita harus menambahkan kolom id_kelas ke dalam tabel users.

1. Update Database Dulu (Wajib!)
Silakan buka phpMyAdmin, masuk ke database lms_sekolah, klik tab SQL, lalu copy-paste perintah ini dan jalankan (Go/Kirim):

SQL
-- Menambahkan kolom id_kelas ke tabel users
ALTER TABLE users ADD COLUMN id_kelas INT NULL AFTER role;

-- Membuat relasi agar id_kelas terhubung ke tabel kelas
ALTER TABLE users ADD CONSTRAINT fk_user_kelas FOREIGN KEY (id_kelas) REFERENCES kelas(id_kelas) ON DELETE SET NULL;
(Catatan: Jika berhasil, ini memungkinkan kita untuk mengelompokkan siswa berdasarkan ruang kelasnya).

3. Buat File tambah_siswa.php

    $nama_lengkap = trim(mysqli_real_escape_string($koneksi, $_POST['nama_lengkap']));
    $username     = trim(mysqli_real_escape_string($koneksi, $_POST['username']));
    $password     = $_POST['password'];
    $id_kelas     = $_POST['id_kelas'];
    
    $password_hash = password_hash($password, PASSWORD_DEFAULT);
    
    // Cek username ganda
    $cek = mysqli_query($koneksi, "SELECT * FROM users WHERE username='$username'");
    if (mysqli_num_rows($cek) > 0) {
        $error = "Username '$username' sudah terdaftar! Gunakan variasi lain, misalnya nama+NIS.";
    } else {
        // Query disesuaikan dengan kolom id_kelas yang baru dibuat
        $query = "INSERT INTO users (username, password, nama_lengkap, role, id_kelas) 
                  VALUES ('$username', '$password_hash', '$nama_lengkap', 'siswa', '$id_kelas')";
                  
        if (mysqli_query($koneksi, $query)) {
            header("Location: data_siswa.php?pesan=sukses");
            exit;
        } else {
            $error = "Gagal menyimpan data: " . mysqli_error($koneksi);
        }
    }
}

Uji Coba Modul Siswa:
Pastikan Anda sudah menjalankan perintah SQL di poin nomor 1.

Buka menu Data Siswa. Tampilannya sudah dilengkapi dengan simulasi "Search Bar" dan tombol "Import Excel" (sebagai hiasan UI agar terlihat sangat profesional).

Klik Tambah Siswa, dan masukkan nama siswa uji coba, pilih kelas yang tersedia, dan klik Daftarkan.

Jika berhasil masuk ke tabel dengan lencana (badge) kelas berwarna hijau, berarti Fondasi Panel Admin Anda sudah SELESAI 100%! 🎉

Admin sudah bisa mengatur Guru, Kelas, Mapel, dan Siswa. Langkah selanjutnya adalah berpindah dari sudut pandang Admin ke Dashboard Guru atau Dashboard Siswa. Mau fokus membuat tampilan untuk siapa dulu? Guru atau Siswa?
