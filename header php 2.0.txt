Itu terjadi karena pada file includes/header.php yang kita buat sebelumnya, warna biru (kelas CSS bg-sekolah-50 text-sekolah-600) masih ditulis secara permanen (hardcoded) pada menu Dashboard.

Agar menu di sidebar bisa mendeteksi secara otomatis halaman apa yang sedang dibuka (dinamis), kita perlu menambahkan sedikit logika PHP menggunakan basename($_SERVER['PHP_SELF']).

Silakan buka kembali file includes/header.php, hapus seluruh isinya, dan ganti dengan kode yang sudah saya buat menjadi dinamis ini:
