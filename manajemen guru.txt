Mantap! Mari kita lanjutkan membangun fitur Manajemen Guru. Fitur ini sangat penting karena admin harus bisa menambahkan akun untuk para guru agar mereka bisa login dan mengunggah materi.

Kita akan membaginya menjadi dua file: satu untuk menampilkan tabel data guru, dan satu lagi untuk form tambah guru. Keduanya akan menggunakan desain Tailwind CSS yang sudah kita atur sebelumnya.

2. Buat File tambah_guru.php (Form & Proses Simpan)
Buat file baru lagi bernama tambah_guru.php di dalam folder admin/. File ini berisi form modern dan kode PHP di bagian atasnya untuk memproses data langsung ke database.

PHP
<?php
session_start();
if (!isset($_SESSION['role']) || $_SESSION['role'] != 'admin') { header("Location: ../index.php"); exit; }

require_once '../config/koneksi.php';

// PROSES SIMPAN DATA JIKA TOMBOL SUBMIT DITEKAN
if (isset($_POST['simpan'])) {
    $nama_lengkap = trim(mysqli_real_escape_string($koneksi, $_POST['nama_lengkap']));
    $username     = trim(mysqli_real_escape_string($koneksi, $_POST['username']));
    $password     = $_POST['password'];
    
    // Hash password demi keamanan
    $password_hash = password_hash($password, PASSWORD_DEFAULT);
    
    // Cek apakah username sudah ada
    $cek = mysqli_query($koneksi, "SELECT * FROM users WHERE username='$username'");
    if (mysqli_num_rows($cek) > 0) {
        $error = "Username sudah digunakan! Silakan pilih username lain.";
    } else {
        // Simpan ke database dengan role 'guru'
        $query = "INSERT INTO users (username, password, nama_lengkap, role) VALUES ('$username', '$password_hash', '$nama_lengkap', 'guru')";
        if (mysqli_query($koneksi, $query)) {
            header("Location: data_guru.php?pesan=sukses");
            exit;
        } else {
            $error = "Gagal menyimpan data: " . mysqli_error($koneksi);
        }
    }
}

include '../includes/header.php';
?>

Cara Mengujinya:
Klik menu Manajemen Guru di sidebar kiri. Karena database kita baru di-reset, tabelnya pasti akan menampilkan pesan "Belum ada data guru." dengan ikon yang rapi.

Klik tombol + Tambah Guru.

Masukkan data contoh:

Nama: Siti Aminah, M.Pd

Username: guru_siti

Password biarkan yapan123

Klik Simpan Data Guru.

Sistem akan memproses data (meng-hash password secara otomatis) dan melempar Anda kembali ke tabel guru dengan notifikasi sukses berwarna hijau!

Apakah penambahan data gurunya berjalan lancar? Jika sudah, kita bisa melangkah ke fitur Mata Pelajaran untuk mengikat guru tersebut ke jadwal kelasnya.
